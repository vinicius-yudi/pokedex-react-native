# Pokédex Explorer com React Native

Um catálogo de Pokémon interativo construído com React Native e Expo, consumindo a PokéAPI. Este projeto foi desenvolvido para aplicar e consolidar conceitos de desenvolvimento de aplicativos móveis com a stack JavaScript, incluindo Componentes Funcionais, Hooks, navegação e gerenciamento de estado global.

# ✨ Funcionalidades

### O aplicativo permite aos usuários:

* Visualizar uma Lista de Pokémon: A tela inicial carrega uma lista de Pokémon em um layout de grade.
* Carregamento Infinito: Role a lista para baixo para carregar mais Pokémon automaticamente.
* Buscar por um Pokémon: Utilize a barra de busca para encontrar um Pokémon específico por nome ou número e ir diretamente para sua tela de detalhes.
* Ver Detalhes: Toque em um Pokémon para ver informações detalhadas, como imagem, tipos e habilidades.
* Gerenciamento de Favoritos: Marque seus Pokémon preferidos na tela de detalhes.
* Tela de Favoritos: Acesse uma tela dedicada para visualizar todos os Pokémon que você marcou como favoritos.
* Feedback de UI: Indicadores de carregamento (ActivityIndicator) e mensagens de erro são exibidos para fornecer um feedback claro ao usuário durante as requisições à API

# 🛠️ Tecnologias e Bibliotecas

### Este projeto foi construído utilizando as seguintes ferramentas:

* Framework: React Native com Expo
* Linguagem: TypeScript
* Navegação: React Navigation (Stack)
* Cliente HTTP: Axios para realizar as chamadas à API.
* Gerenciamento de Estado: React Context API para o controle global dos Pokémon favoritos.
* Armazenamento Local: AsyncStorage para persistir a lista de favoritos no dispositivo.
